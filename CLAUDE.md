## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on bizz84/currency_converter, using the `gh` CLI. See `ai_docs/agents/issue-tracker.md`.

### Triage labels

The five default labels are used as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `ai_docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the repo root and ADRs in `ai_docs/adr/`. See `ai_docs/agents/domain.md`.
